# Fonts

All fonts are from Google Fonts (SIL Open Font License 1.1), taken from the
`@fontsource/*` npm packages and rebuilt by `thumbnail/tools/build_fonts.py`
(Devanagari + Latin glyphs merged into one TTF so text like "5 आदतें!" works).

| Key in config        | File                          | Use |
|----------------------|-------------------------------|-----|
| `noto-black` (default) | NotoSansDeva-Black.ttf      | Heavy Hindi heading – closest to the reference thumbnails |
| `noto-extrabold`     | NotoSansDeva-ExtraBold.ttf    | Slightly lighter Hindi |
| `yatra`              | YatraOne-Deva.ttf             | Brush / festive Hindi |
| `rozha`              | RozhaOne-Deva.ttf             | High-contrast serif Hindi |
| `baloo`              | Baloo2-Deva-ExtraBold.ttf     | Rounded heavy Hindi |
| `mukta`              | Mukta-Deva-ExtraBold.ttf      | Clean heavy Hindi |
| `khand`              | Khand-Deva-Bold.ttf           | Condensed – long Hindi words |
| `poppins-black` (default English) | Poppins-Black.ttf | English power words (CONTROL, FOCUS…) |
| `poppins-extrabold`  | Poppins-ExtraBold.ttf         | Watermark |
| `montserrat-black` / `montserrat-extrabold` | Montserrat-*.ttf | Alternative English |

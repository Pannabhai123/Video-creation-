# YouTube Shorts (9:16) स्क्रिप्ट टेम्पलेट

> 20–58 सेकंड। पहला सेकंड ही सब कुछ है।

## ढाँचा

| समय | तत्व | नियम |
|---|---|---|
| 0.0–1.0s | दावा या झटका | पहले शब्द में ही मुद्दा; कोई "नमस्कार" नहीं |
| 1–5s | कारण | क्यों यह जानना ज़रूरी है |
| 5–25s | विचार | एक ही विचार, दो से ज़्यादा नहीं |
| 25–45s | उदाहरण/कदम | ठोस, लागू करने योग्य |
| 45–55s | बंद करने वाला वाक्य | दोहराया जाने वाला एक वाक्य |
| अंतिम 2s | लूप | आख़िरी शब्द पहले शब्द से जुड़े (रीवॉच) |

## लेखन नियम
- कुल 90–130 हिन्दी शब्द (≈45 सेकंड)।
- सबटाइटल दो पंक्तियों से ज़्यादा नहीं, हर पंक्ति 28 अक्षर तक (9:16 संकरा है)।
- एक वाक्य = एक शॉट। हर 3–4 सेकंड में दृश्य बदलें।
- टेक्स्ट स्क्रीन के बीच के 70% हिस्से में रहे (ऊपर/नीचे UI कटता है)।

## तकनीकी
- `project.json` में `"format": "short"`, `"preset": "shorts_1080x1920"`।
- लंबी वीडियो से काटते समय: `python automation/projector.py shorts projects/<id>/project.json --count 3`
- काटने के बाद हमेशा पहला फ़्रेम जाँचें — दृश्य बीच से न कटे। 8 सेकंड से छोटे सीन
शॉर्ट्स के लिए नहीं काटे जाते; उन्हें अलग शॉर्ट स्क्रिप्ट से बनाएँ।

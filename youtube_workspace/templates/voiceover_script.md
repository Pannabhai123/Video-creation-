## रिकॉर्डिंग निर्देश (अगर खुद बोलें)
- माइक मुँह से 15–20 सेमी, थोड़ा किनारे (प्लोसिव कम करने के लिए)
- एक ही सत्र में सारे सीन; हर सीन से पहले 1 सेकंड चुप्पी, बाद में 1 सेकंड
- गलती हो तो पूरा वाक्य दोहराएँ — बीच से काटने की ज़रूरत न पड़े
- कमरा: सोफ़ा/किताबों के बीच, पर्दे बंद; पंखा/AC बंद

## प्रोसेसिंग

```bash
# फ़ाइलें आयात करें (कोई भी फ़ॉर्मैट):
python automation/vo.py import --project projects/<id>/project.json --src ~/Downloads/vo

# एक ही लंबी रिकॉर्डिंग को सीन में बाँटें:
python automation/vo.py split --project projects/<id>/project.json --file ~/take.m4a

# स्तर एकसमान करें, फिर जाँचें:
python automation/vo.py normalize --project projects/<id>/project.json
python automation/vo.py check --project projects/<id>/project.json
```

TTS से बनाए गए ऑडियो के लिए भी यही प्रक्रिया — बस फ़ाइलों के नाम सीन आईडी रखें।

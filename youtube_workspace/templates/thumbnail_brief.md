## 5. बनाने का तरीका

```bash
# brief को JSON में लिखें, फिर:
python automation/thumbnail.py --spec projects/<id>/thumb.json --out thumbnails/<id>.png

# मोबाइल आकार में जाँच:
python automation/thumbnail.py --demo --out thumbnails   # उदाहरण देखने के लिए
```

`thumb.json` का ढाँचा:

```json

  "headline": "2 मिनट का नियम",
  "kicker": "PRODUCTIVITY",

  "photo": "images/subject.png",

}
```

# Production Error Log & Verified Solutions

Maintain this log whenever a tool, dependency, or rendering issue occurs so future sessions never repeat failed approaches.

---

### ERR-001: Debian `apt-get` Mirrors Blocked in Sandbox
- **Date:** 2026-10-24
- **Symptom:** `deb.debian.org` and `security.debian.org` fail HTTP/HTTPS connection due to sandbox outbound host allowlist.
- **Root Cause:** Outbound network access is restricted to `github.com`, `codeload.github.com`, `api.github.com`, `registry.npmjs.org`, `pypi.org`, and `files.pythonhosted.org`.
- **Verified Solution:** Do **not** run `apt-get update` or `apt-get install`. Use `scripts/setup_environment.sh`, which installs static `ffmpeg` (`imageio-ffmpeg`), static `ffprobe` (`@ffprobe-installer/linux-x64`), self-contained `Chromium 153` (`@sparticuz/chromium`), and `libespeak-ng.so` (`espeakng-loader`) directly from allowed PyPI/npm packages.

### ERR-002: `ffmpeg-static` npm Postinstall Certificate/Egress Failure
- **Date:** 2026-10-24
- **Symptom:** `npm install ffmpeg-static` fails in `node install.js` with `UNABLE_TO_VERIFY_LEAF_SIGNATURE`.
- **Root Cause:** `ffmpeg-static` downloads binaries at install time from `objects.githubusercontent.com`, which is blocked by the sandbox proxy.
- **Verified Solution:** Never install `ffmpeg-static`. Copy the bundled FFmpeg 7.0.2 binary directly from Python's `imageio_ffmpeg.get_ffmpeg_exe()` to `/usr/local/bin/ffmpeg`.

### ERR-003: Remotion Default Browser Download & Missing `libnss3.so`
- **Date:** 2026-10-24
- **Symptom:** Remotion attempts to download Chrome Headless Shell from `storage.googleapis.com` (blocked), and bare Chromium fails with `libnspr4.so / libnss3.so: cannot open shared object file`.
- **Root Cause:** Base container lacks X11/NSS system packages and blocks Google Storage.
- **Verified Solution:** Decompress `chromium.br`, `al2023.tar.br` (contains `libnss3.so`, `libnspr4.so`, `libnssutil3.so`), `swiftshader.tar.br`, and `fonts.tar.br` from `@sparticuz/chromium` into `/usr/local/lib/chromium-headless` and expose `/usr/local/bin/chromium` with `LD_LIBRARY_PATH` and `--use-gl=angle --use-angle=swiftshader`. Automated in `scripts/setup_environment.sh`.

### ERR-004: H.264 SPS/PPS Mismatch in FFmpeg `-f concat -c copy`
- **Date:** 2026-10-24
- **Symptom:** Stream-copying (`-c copy`) segments generated by mixed encoders (Remotion FFmpeg 7.1 + MoviePy/FFmpeg 7.0.2) caused frozen frames at segment boundaries.
- **Root Cause:** Incompatible H.264 SPS/PPS codec extradata and timebases across encoders during `-c copy` concat.
- **Verified Solution:** Concatenate segments via decoded `filter_complex` (`[0:v]...[N:v]concat=n=N:v=1:a=0[vcat]`) inside `yt_studio/renderer.py` during the final YouTube mastering pass.

### ERR-005: `espeak-ng` Hindi Word-Boundary Timestamp Offset Drift
- **Date:** 2026-10-26
- **Symptom:** Mapping `espeak_EVENT.text_position` against UTF-8 byte offsets worked for ASCII English (`1 char = 1 byte`) but drifted on multi-byte Hindi Devanagari (`1 char = 3 bytes`).
- **Root Cause:** `espeak_EVENT.text_position` in `espeakCHARS_UTF8` mode reports **1-based Unicode character (codepoint) indices**, not UTF-8 byte indices.
- **Verified Solution:** Updated `synthesize_espeak_segment` in `yt_studio/audio_engine.py` to index whitespace-delimited tokens by Unicode character offsets (`len(tok)`). Verified accurate on Hindi Devanagari sentences.

### ERR-006: Broken Devanagari Conjuncts & `ि`-Matra Ordering in Pillow / Static `libass`
- **Date:** 2026-10-26
- **Symptom:** Pillow (`ImageDraw.text`) without `libraqm` rendered `विज्ञान` with misplaced `ि`-matra, and John Van Sickle static FFmpeg `libass` (compiled without `libharfbuzz`) rendered visible halants in `नमस्ते दोस्तों` (`नमस््ते`).
- **Root Cause:** Proper Indic/Devanagari OpenType GSUB/GPOS shaping requires HarfBuzz.
- **Verified Solution:** Route Hindi/Indic video rendering and thumbnail generation (`engine="auto"` in `yt_studio/renderer.py` & `yt_studio/graphics.py`) through **Remotion + Headless Chromium 153**, which includes full Blink + HarfBuzz Indic text shaping (`YouTubeShowcase` + `SubtitleOverlay` + `YouTubeThumbnail`), while still embedding soft `.srt` `mov_text` tracks.

### ERR-007: Container Cold-Boot Wipes `/usr/local` & `node_modules`
- **Date:** 2026-10-26
- **Symptom:** After multi-day idle cold-boot, files in `/home/user/Video-creation-` persisted, while `/usr/local/bin/{ffmpeg,chromium}`, system Python packages, and `node_modules` reset to base image state.
- **Root Cause:** Platform snapshots persist workspace files under `/home/user` (excluding `node_modules`, `.venv`, `.cache`, `out`, `dist`, `build`), not root OS paths outside `/home/user`.
- **Verified Solution:** Run `bash scripts/setup_environment.sh` only when `command -v ffmpeg` or `node_modules/remotion` is missing. Restores the complete stack in ~55s without touching existing project files.

# Channel Preferences & Content Policy

**Last Updated:** 2026-10-26  
**Status:** Active Default Policy for All YouTube Video Production Tasks

---

## 1. Channel Focus & Core Niches
- **Book Summaries**
- **Self-Improvement**
- **Personal Development**
- **Psychology**
- **Productivity**
- **Habits and Discipline**
- **Motivation**
- **Educational Content**

---

## 2. Default Language & Tone
- **Default Narration & Subtitle Language:** **Hindi (`hi` / Devanagari)** unless explicitly overridden by the user for a specific request.
- **Tone & Style:** Professional, educational, engaging, clear, structured, and suitable for long-form YouTube audiences.
- **Pacing:** ~145–155 words per minute, clear articulation, synchronized readable phrase captions.

---

## 3. Editorial, Factual & Visual Standards
1. **Originality:** Write 100% original scripts tailored to the requested topic or book.
2. **Fact & Quote Integrity:**
   - **Never fabricate facts, statistics, studies, author claims, or direct quotations.**
   - Paraphrase core book frameworks accurately when exact verbatim quotes are not verified from primary text.
   - Verify key factual claims (author names, publication years, psychological experiments, named frameworks) before script lock.
3. **Practical Pedagogy:** Explain abstract psychological or productivity concepts through concrete, relatable real-life examples and actionable takeaways.
4. **Visual Consistency:**
   - Use scene-specific visuals aligned directly to each scene's concept.
   - Maintain a cohesive studio color palette, typography (`Poppins` + `Noto Sans Devanagari`), and framing across all scenes.
   - Convert static images into dynamic motion clips (Ken Burns zoom/pan, smooth transitions, animated callout text).
5. **Honest Packaging:**
   - Create high-contrast, readable titles and thumbnails (`1280x720` and `1920x1080`).
   - **Avoid misleading clickbait** or exaggerated claims not supported by the video content.
6. **Copyright & Licensing Compliance:**
   - Use only original AI-generated visuals, procedural studio graphics, copyright-safe synthesized music/SFX, or properly licensed user-provided media.
   - Never use copyrighted commercial music, watermarked stock assets, or unlicensed book text excerpts beyond fair educational summary principles.

---

## 4. Interaction & Authorization Rules
- **Minimum Friction:** Apply sensible defaults automatically; ask clarifying questions **only** when essential information is genuinely missing.
- **Strict Authorization Boundaries:**
  - Never purchase subscriptions or spend money without explicit user permission.
  - Never publish/upload videos publicly without explicit user permission.
  - Never expose API keys, tokens, or credentials in project files, logs, or commits.
  - Never perform destructive repository or file deletions without explicit user permission.
